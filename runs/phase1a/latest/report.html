当前 Workflow

1 输入目标

water_dispenser，anchor 为 indoor_map。

2 查询记忆

如果有 reusable 目标，直接生成 memory candidate。

3 探索 Frontier

空记忆时选择 known-side frontier viewpoint，前进并 reveal unknown。

4 Fake Detection

机器人进入距离、FOV、LOS 条件后才产生 object observation。

5 Verification

导航到饮水机前方 viewpoint，不导航到物体中心。

6 更新记忆

写入 SQLite，后续 trial 可复用或触发 missing/relocation。

ROS 2 边界： 当前 workflow 是 ROS-free core。未来 objectnav_ros 只负责把 ROS topic、TF、Nav2 action、相机/RTK 数据翻译成 core 的接口输入。
