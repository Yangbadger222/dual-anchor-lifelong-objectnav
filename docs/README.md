# Documentation Index

This directory stores the project memory. Keep it useful enough that a new human or AI agent can resume work without asking what happened last time.

## Structure

| Directory | Purpose |
|---|---|
| `design/` | Design docs for architecture, modules, algorithms, and interfaces |
| `devlog/` | Chronological development records |
| `experiments/` | Experiment protocols, results, and analysis |
| `handoff/` | Current state and continuation notes |
| `decisions/` | Architecture and research decision records |
| `templates/` | Required templates for repeatable documentation |

## Rule of Thumb

If a future contributor would need to ask "why did we do this?", write it down.
