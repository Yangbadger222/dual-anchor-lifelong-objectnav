# Experiment Report: Official Memory Anchor TargetNav Backend Smoke

Date: 2026-05-31
Owner: Codex
Status: Completed

## Question

Can the base official TargetNav memory policy execute a selected remembered
anchor through `--targetnav-backend oracle_follower`, and what does that reveal
about the current YOLO-discovered memory prior?

## Hypothesis

If the selector now uses memory anchors directly, the tv-monitor episode should
activate the oracle backend at step `0` from the remembered anchor rather than
waiting for a fresh target detection. Because the prior was generated by a noisy
detector, this is a diagnostic of memory-anchor quality, not a benchmark-valid
performance claim.

## Observations

- The tv-monitor episode selected the remembered anchor with source
  `yolo_world:yolov8s-worldv2.pt:episode=0:step=6:detection=1`.
- The anchor was `x_m=-2.319286`, `z_m=0.0115`,
  `coordinate_frame=episode_start_relative`, confidence `0.80616`.
- The oracle backend converted that anchor to Habitat world goal
  `[-0.5231360709882893, -0.00508, -5.054317485023427]` and reported
  `status=SUCCEEDED`, `reason=oracle_follower_stop`,
  `privileged_oracle=true`, and `benchmark_valid=false`.
- Official distance after the tv-monitor episode was `6.225101470947266`,
  much worse than the previous detector-triggered oracle selector smoke, where
  the tv-monitor episode ended at distance about `0.7463`.
- This strongly suggests the current YOLO-discovered memory anchor is poorly
  localized or stale for this query, rather than the failure being caused only
  by low-level local control.

## Result

The memory anchor now genuinely drives the selected backend. The diagnostic
result is negative but valuable: direct oracle execution exposes that the
current discovered prior is not paper-quality memory yet. The next paper-facing
work should improve memory-anchor reliability, stale-anchor handling, or
candidate scoring instead of treating the old FMM failures as the only problem.

## Follow-up

- Add an oracle/ground-truth memory-prior upper-bound exporter to validate the
  episode-relative-to-world transform and quantify the gap between perfect
  memory and YOLO-discovered memory.
- Improve memory anchor quality with multi-view fusion or confidence calibrated
  from future re-observation evidence.
- Keep these oracle-backed numbers diagnostic only.
