一句话结论

当前最强结果是六类别均衡的 Habitat oracle/action stale repeat： memory_guided 用 2020 actions 完成 12/12， 明显优于 frontier_only 的 3074 和 naive_count 的 4148。这说明方向对了， 但它仍然只是 oracle/action smoke，不是 Grounding-DINO 闭环、 不是真 frontier、也不是 official SPL。

这轮具体做了什么

  • 把 Habitat runner 从单次 stable smoke 扩展到 stable、ambiguous、stale_proxy。
  • 修复 repaired memory：修复后的 anchor 现在走 direct memory route，不再错误按 frontier proxy 计费。
  • 加入 expected-utility 决策：agent 可以选择先去 memory pose，或先去 frontier/search proxy。
  • 保留公平 baseline：naive_count 仍然是最朴素 positive-only，不吃 non-confirmation、unknown、delayed birth 或 repaired anchor。
  • 加入类别均衡 selection：--max-groups 6 优先覆盖 bed/chair/plant/sofa/toilet/tv_monitor 六类。
  • 把负结果写进报告，避免把 debugging artifact 包装成漂亮结论。

负结果和修复历史

  • 第一版 stable smoke 三个 policy 动作数相同，因为 frontier baseline 实际走到了同一个 target viewpoint，不是探索 baseline。
  • 第一版 challenge smoke 中 ambiguous label 和 stale fallback 语义不完整，已经用 regression tests 修掉。
  • repaired memory 一开始被错误按 frontier proxy route 计费，导致 memory 在 stale repeat 里输给 frontier；修复 direct route 后单组 plant 从 545 降到 446 actions。
  • 没有 expected utility 的 unbalanced max6 会在部分 group 盲目探旧 memory，说明 stale-risk 决策是必要算法点，不是可有可无的指标修饰。
  • memory_valid_prior=0.8 比 0.5 更差，说明 prior 不能靠手调写死，后面要从证据、类别、协方差、session age 中估计。

目前还不能声称什么

这还不是顶会主结果。当前仍然是 oracle semantic visibility + action-route smoke。 不能把它写成 Grounding-DINO 闭环、真实 frontier、自然物体搬移、或者 Habitat official SPL。

  • 还没有 Grounding-DINO per-step perception。
  • frontier 还是 deterministic search proxy，不是真 occupancy frontier。
  • stale_proxy 仍是 protocol-level stale，不是 Habitat 中真的搬动物体。
  • 六个 group 只是小规模 smoke，需要扩到更多 scene/group 并给出方差。

下一步

  1. 把 oracle visibility 换成 Grounding-DINO observations，保持同一套 gate 和 policy accounting。
  2. 实现真 frontier mapping/exploration，替换 search proxy。
  3. 做自然 staleness：优先尝试 Habitat object hide/replace 或可审计的 semantic-object relocation。
  4. 把 balanced runs 扩到更多 group，输出 confidence interval。
  5. 把 memory_valid_prior 从手设值变成证据驱动或可学习估计。
  6. 等 per-action perception 和真 frontier 稳定后，再做 SPL-like 或 official benchmark 对比。
