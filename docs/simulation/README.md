# Simulation Docs

This directory stores simulation-specific protocols and operation guides.

Use it for Habitat-Sim, Habitat-Lab, Gazebo, and future simulator replay workflows when the document is mainly about how to run or reproduce a simulated experiment. Keep algorithm design docs in `docs/design/` and completed result reports in `docs/experiments/`.

Recommended naming:

```text
YYYY-MM-DD-short-topic.md
YYYY-MM-DD-short-topic.zh.html
```
